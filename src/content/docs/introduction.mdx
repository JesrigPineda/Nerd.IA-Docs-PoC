Esta documentación organiza una integración pequeña alrededor de un objetivo: enviar un primer mensaje con Nerd.IA. Empieza con el [Inicio rápido](/quickstart/) y usa la [Referencia API](/api-reference/) cuando necesites el contrato técnico.

Todo dato de la API se limita a la [documentación pública original](https://nerds.notion.site/API-Doc-77a08e24d2a34c098fcd24658041e842). Los vacíos detectados se publican en [Información no especificada](/known-gaps/).
